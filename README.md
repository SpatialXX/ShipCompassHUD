# Flight Path Vector
 This mod adds 7 markers from Kerbal Space Program to help you visualize your ship trajectory

**Features**

<img src="https://wiki.kerbalspaceprogram.com/images/a/a4/Prograde.svg" width="30" height="30" /> **Prograde :** Will point in the direction in which your ship is heading 

<img src="https://wiki.kerbalspaceprogram.com/images/0/02/Retrograde.svg" width="30" height="30" /> **Retrograde :** Will point in the direction opposite to which your ship is heading

<img src="https://wiki.kerbalspaceprogram.com/images/8/81/Radial-in.svg" width="30" height="30" /> **Radial-In :** Perpendicular to the Prograde, will point toward the selected target

<img src="https://wiki.kerbalspaceprogram.com/images/9/9a/Radial-out.svg" width="30" height="30" /> **Radial-Out :** Perpendicular to the Prograde, will point away from the selected target

<img src="https://wiki.kerbalspaceprogram.com/images/0/01/Normal.svg" width="30" height="30" /> **Normal :** Parallel to the selected target, it points to the right of the target

<img src="https://wiki.kerbalspaceprogram.com/images/1/19/Anti-normal.svg" width="30" height="30" /> **Anti-Normal :** Parallel to the selected target, it points to it's the left of the target


<img src="https://wiki.kerbalspaceprogram.com/images/1/1f/Maneuver.svg" width="30" height="30" /> **Maneuver :** Adjustable marker, will point in a direction selected by the player

-**Artificial Horizon :** Two lines parallel to the target, symbolize the ship's rotation relative to the ground
